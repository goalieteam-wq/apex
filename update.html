APEX · обновление

Нажми кнопку — скачается файл UPDATE.command.
Это тот же «ОБНОВИТЬ», просто с именем, которое браузер скачивает без лишних вопросов.

прямая ссылка (если кнопка не сработала)
  1. Файл окажется в папке «Загрузки».
  2. Двойной клик по нему. Если Mac скажет «нельзя проверить разработчика» — правый клик → Открыть → Открыть (нужно один раз).
  3. Скрипт сам обновит проект и откроет Xcode: выбери свой iPhone сверху → ▶.

А ещё проще: файл ОБНОВИТЬ.command уже лежит в папке apex-native на Mac и сам себя обновляет — просто открой её в Finder и запусти двойным кликом. Ничего скачивать не нужно.
