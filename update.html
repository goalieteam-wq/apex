APEX · обновление

Жми зелёную кнопку — скачается архив UPDATE.zip.
В нём — обновлятор с уже выставленным правом запуска, ошибка «нет прав доступа» исчезла.

СКАЧАТЬ ОБНОВЛЕНИЕ запасная ссылка (.command, может показать текст — так и должно быть)
  1. Открой папку «Загрузки» — там лежит UPDATE.zip. Двойной клик по нему — рядом появится файл UPDATE.command.
  2. Двойной клик по UPDATE.command. Если Mac скажет «нельзя проверить» — правый клик → Открыть → Открыть (только один раз).
  3. Дальше всё само: обновит проект и откроет Xcode — выбери свой iPhone сверху → ▶.
  4. После первого запуска на Рабочем столе появится кнопка «APEX ОБНОВИТЬ» — следующие обновления делаются одним двойным кликом по ней, без скачиваний.

Где моя папка apex-native?

Нажми Cmd + Пробел, набери apex-native и щёлкни по найденной папке — Finder сам её откроет.
